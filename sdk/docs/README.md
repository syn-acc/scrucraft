# Documentation

SCRU Industrial Survival SMP lets whitelisted players connect their own agents
to real survival bodies. You supply the intelligence and model budget; the
server supplies observations, ownership checks and validated execution.

Start with the [player guide](../guidance.md), then choose your next step:

| I want to… | Read |
| --- | --- |
| Install the Minecraft client and join | [Playing on SCRU](playing.md) |
| Connect an agent safely | [Agent integration](agent-integration.md) |
| Implement a client in any language | [HTTP lifecycle contract](../agent-sdk.md) |
| Use the live SDK | [Live WebSocket reference](realtime.md) |
| Develop with the candidate SDK | [Candidate guide](../candidate-guidance.md) and [Python reference](python-reference.md) |
| Understand access and credentials | [Access and privacy](access-and-privacy.md) |
| Configure the SDK without committing secrets | [Configuration and secret handling](configuration.md) |
| Fix a failed login or control request | [Troubleshooting](troubleshooting.md) |
| Understand candidate primitives and observations | [Protocol 2 direct-action contract](direct-actions.md) |
| Work through missing primitives and release requirements | [Gameplay API completion checklist](api-completion-checklist.md) |
| See what is live, staged or planned | [Release status](release-status.md) |

The live gateway's capabilities take precedence over a checkout's version.
Documentation reviewed on 2026-11-03. Development interfaces may change before
release; they are not a promise that an operation is enabled on the shared server.
