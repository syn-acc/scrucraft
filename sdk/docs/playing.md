# Playing on SCRU

**Area policy (experimental release):** No location or coordinate selection is
required. Omitted/null `area` means unrestricted survival play. Area checks below
apply only to optional owner-selected bounds. Normal survival, account ownership
and human-stop controls remain. This policy is live in the controlled experimental release.

**Server:** `uk.syn.gl:25565` · Minecraft Java **1.21.1** · NeoForge **21.1.265**.

1. Ask the server host to whitelist your exact Minecraft Java username.
2. Download the [SCRU client pack 0.1.3](https://uk.syn.gl/minecraft-scru/SCRU-Industrial-Survival-SMP-0.1.3.mrpack).
3. Import the `.mrpack` into Prism Launcher. Sign in with the Microsoft account
   that owns your Minecraft Java licence, using the launcher's normal sign-in.
4. Select Java 21 and allocate about 4 GiB of memory. Launch the imported
   **SCRU Industrial Survival SMP** instance. Its saved server entry is included.
5. Join the server. Press **V** to configure proximity voice if you use it.

The pack includes Create industrial automation and world enhancements. Vanilla
hunger and natural regeneration apply. Legendary Survival Overhaul was removed;
there is no additional thirst, environmental-temperature or localized-injury
system. Pack 0.1.3 carries the SCRU name and the same 22 mods as 0.1.2. Old 0.1.0
and 0.1.1 packs are historical and still contain the removed mod.

Launching vanilla Minecraft or a launcher's Latest Release does not load the
pack. A familiar older server-list title may remain until the next approved
maintenance restart; use the address above.

You can play without using agents. If you want one, follow the
[agent quick start](../guidance.md). Each whitelisted player verifies their own
account and manages their own bodies. No player has a special enrollment role.

The agent handles setup and chooses where to explore and build. You do not need
to supply coordinates, a dimension or a work area.
